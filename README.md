# ContactHup 📇 — Assignment 9

ContactHup is a smart contact management web application built with HTML, CSS, JavaScript, and Bootstrap.

## ✨ Features

* Add, edit, and delete contacts
* Store contacts using LocalStorage
* Search contacts by name, phone, or email
* Mark contacts as Favorites
* Mark contacts as Emergency contacts
* Organize contacts into groups
* Form validation using Regular Expressions
* Display total, favorite, and emergency contact counts
* Responsive design using Bootstrap
* SweetAlert notifications
* Call and email contacts directly

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* Bootstrap
* Font Awesome
* LocalStorage
* SweetAlert2
